# Sailing GPS Logger Web V7

## V7の変更

- 三角形の回転をCSS transitionからrequestAnimationFrame方式へ変更
- 方位更新直後から滑らかに追従
- 360°と0°の境界で遠回りせず、最短方向へ回転
- GPS・磁気コンパスの更新間隔の間も連続アニメーション
- 磁気方位の平滑化を速め、反応の遅れを軽減

## 維持している機能

- 三角形の頂点はコンパス外向き
- 右方向は緑、左方向は赤
- SOG 0.0 ktでは磁気コンパス
- SOG 0.1 kt以上ではGPS COG
- 複数ウェイポイント
- GPX・CSV保存
- PWA対応

## GitHub Pagesへの反映

ZIPを展開し、リポジトリ直下へ全ファイルを上書きしてください。
古い表示や動作が残る場合は、ホーム画面のPWAを削除し、ブラウザのサイトデータを消してから再登録してください。
