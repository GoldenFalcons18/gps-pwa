# Sailing GPS Logger Web V6

## V6の修正

- コンパス外周の方向表示を三角形のまま維持
- 三角形の頂点が円の外側を向くよう修正
- 三角形の底辺が円の中心側になるよう修正
- 三角形はウェイポイント方向に合わせて外周を回転
- 右方向は緑、左方向は赤
- 中央の角度表示と重ならない配置

## 維持している機能

- SOGが0.0 ktの場合は磁気コンパスを使用
- SOGが0.1 kt以上の場合はGPS COGを使用
- 複数ウェイポイントの保存・選択・削除
- GPX・CSV保存
- PWA対応

## GitHub Pagesへの反映

ZIPを展開し、リポジトリ直下のファイルをすべて上書きしてください。
古い表示が残る場合は、ホーム画面のPWAを削除してブラウザのキャッシュを消し、再登録してください。
