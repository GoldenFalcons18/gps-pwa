# Sailing GPS Logger Web V2

## 主な変更
- 参考画像に近い3分割の計器配置
- 文字と数値を大型化
- 中央計器を「前方0°」と「絶対方位」で切替可能
- ウェイポイントが右側なら緑、左側なら赤
- 相対方位を12時方式と左右度方式で表示
- 計器下にSOG・COGを大型表示
- GPX / CSV保存
- PWA対応

## GitHub Pagesへの反映
ZIPを展開し、リポジトリ直下の同名ファイルをすべて上書きしてください。
特に index.html と service-worker.js は必ず更新してください。

更新後に古い画面が出る場合：
- iPhone: ホーム画面のアプリを削除し、Safariで再度開いてホーム画面へ追加
- Chrome: サイトデータまたはキャッシュを削除して再読み込み
