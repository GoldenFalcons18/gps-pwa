# Sailing GPS Logger Web V5

## V5の変更
- ウェイポイント表示を「矢印」から外周だけに置く三角形へ変更
- 三角形の向きを修正
- 三角形は先端がウェイポイント方向を向く
- 中央の角度表示と重ならない配置
- 右方向は緑、左方向は赤
- SOG 0.0 ktでは磁気コンパス、0.1 kt以上ではGPS COGを使用
- 複数ウェイポイント保存・選択・削除に対応

## GitHub Pagesへの反映
1. ZIPを展開
2. リポジトリ直下へ全ファイルを上書きアップロード
3. Commit changes
4. 古い表示が残る場合はPWAを削除し、キャッシュ削除後に再登録
